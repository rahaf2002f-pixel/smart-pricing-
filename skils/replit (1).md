# التسعير الذكي للمتاجر - smart pricing AI

## Problem
اصحاب المتاجر الاكترونيه الصغيره يواجهون صعوبه في تحديد اسعار منتجاتهم لانهم مايسحبون جميع التكاليف وهذا ممكن يودي الى تقليل الارباح او الخساره

## User
اصحاب المتاجر الاكترونيه يغيره خصوصا متاجر المكياج والعطور و الاكسوارات الي يواجهون صعوبه في حساب تكلفه المنتجات وتحديد سعر البيع المناسب

## Solution
نساعد اصحاب المتاجر الاكترونيه على حساب التكلفه الاجماليه لكل منتج وتحديد سعر البيع المناسب وحساب الربح و المتوقع من خلال حسابه ذكيه سهله الاستخدام

## Differentiator
يساعد المستخدم على اكتشاف التكاليف اللي ممكن ينساها، مثل التغليف ورسوم الدفع الإلكتروني والتوصيل، ويقارن بين أسعار البيع المختلفة لمعرفة تأثيرها على الربح.

## MVP features (build only these)
- إدخال تكلفة شراء المنتج.
- إضافة تكلفة التغليف والتوصيل ورسوم الدفع.
- حساب التكلفة الإجمالية تلقائيًا.
- حساب الربح المتوقع وهامش الربح.
- اقتراح سعر بيع بناءً على هامش الربح المستهدف.
- مقارنة الأرباح عند تغيير سعر البيع

## Vision (do not build yet)
أن يصبح Smart Pricing AI المنصة المفضلة لأصحاب المتاجر الإلكترونية الصغيرة في الكويت، لمساعدتهم على تحديد أسعار عادلة ومربحة، وفهم تكاليف منتجاتهم، واتخاذ قرارات ماليه ذكيه تدعم نمو مشاريعهم واستدامتها

## Stack
- Frontend: React with Vite
- Backend: Node.js and Express
- Database: MongoDB Atlas with Mongoose
- Payments: Stripe test mode only, if needed

## Rules
- Build one feature fully, then the next.
- Small steps. Explain each change.
- Never put secrets in code. Use Replit Secrets or .env.
- Do not add features that are not in the MVP list.
